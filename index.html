Features

Four toolkits. One prompt.

Everything DiscordUtility can do, module by module — pick one and see exactly what it looks like in the terminal.

Know your whole circle

One command dumps your entire friend list — username, tag, ID, avatar color and the exact date each friendship started. Search it instantly, or get the numbers behind years of adds.

  • Instant search across hundreds of friends — by name or @username
  • Statistics: total friends, oldest friendship, newest add
  • Avatar colors & IDs rendered right inside the terminal
$ friends --search nova

── 1 result out of 237 friends ──
● Nova        @nova · id 4281037460184 · added 03/12/2019

search took 0.02s — 'friends' lists everyone

DM one, a few, or all of them

Send a direct message to a single friend, a hand-picked selection, or your entire list in one sweep. DM-all comes with a live progress bar and a delay you control — so requests stay spread out instead of hammering the API.

  • DM a single friend, or pick multiple recipients
  • DM-all with a live progress bar & configurable delay
  • Attach files & images to any message
$ dm-all -m "merry christmas!" --delay 2.5

 sending to 237 friends  ███████████░░░░░░░░░░ 47%
 delay 2.5s · rate-limit auto-retry armed

✔ 111/237 sent · 0 errors · ETA 5m12s

Your account, laid bare

Pull your own account details — ID, username, email, flags — then walk through every server you've ever joined. Cleaning house? Leaving a server is one command, safely hidden behind a confirmation prompt.

  • Full account info: ID, email, 2FA status, premium
  • Every joined server with member counts & your role
  • Leave any server — only after a y/N confirmation
$ leave "Lo-Fi Lounge"

⚠ leave Lo-Fi Lounge? this cannot be undone [y/N] y
✔ you left Lo-Fi Lounge — 22 servers remaining

Built like a power tool

The scary parts are wrapped in guardrails. Every destructive action asks before it acts, rate limits are handled with automatic retries and backoff, and the whole interface is colorized and translated — the CLI ships in several languages.

  • Rate-limit aware: automatic retry with backoff
  • Confirmation prompts on every destructive action
  • Colored output & multilingual interface (EN / FR / ES)
$ dm @nova "check this out" --attach ./notes.pdf

rate-limit hit — waiting 1.8s before retry (2/5)
✔ message delivered · notes.pdf uploaded (2.4 MB)

Install

Up and running in three lines.

DiscordUtility is a single Python project with one dependency. If you have Python 3.8 or newer, you're already done.

01

Clone the repository

$ git clone https://github.com/DiscordUtility/DiscordUtility.git
02

Install the single dependency

The only requirement is requests — no compiled extensions, no bloat.

$ pip install -r requirements.txt
03

Launch the tool

On first run the tool asks for your token. It is stored locally and never leaves your machine.

$ python main.py
Your token is your account. Paste it nowhere except the tool's own prompt — anyone who holds it owns your account.

Read this before you run anything

DiscordUtility talks to Discord through private endpoints and a user authentication token. That is against Discord's Terms of Service, and Discord reserves the right to disable or permanently ban any account that does it. This project exists to study how Discord's API works — nothing more.

  • Self-bot automation breaks Discord's Terms of Service — it applies to every command here, even the harmless-looking ones.
  • Discord actively detects user-token traffic. Accounts get phone-locked, disabled, or permanently banned.
  • The authors take zero responsibility for your account. If you run this on a real account, the risk is entirely yours.

"If you only want to understand the API, read the source. Running a self-bot on an account you care about is never worth it."
