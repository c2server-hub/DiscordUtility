A boot sequence worth watching

Every launch opens like an old machine waking up: CRT power-on, a BIOS POST that stalls at 99%, a burst of static, a hyperspace roll — then a lit 3D core, and the ASCII banner decoding itself out of glitch, character by character. Any key skips it. Nobody skips it.

  • CRT power-on & shutdown — the screen opens like a tube TV and closes to a single dot
  • BIOS POST, signal loss, hyperspace and a lit 3D torus core — z-buffer & specular, donut-style
  • Glitch-decoded banner, animated module checks, pixel-typed welcome — in true color

DM one, a few, or everyone at once

Pick a single friend, a handful by number, or the entire list. Every send is preceded by a recap panel — recipients, message, attachment — and campaigns run with a live bar, per-friend results and an animated cooldown.

Install

Up and running in three lines.

DiscordUtility is a single Python project with one dependency. If you have Python 3.7 or newer, you're already done.

01

Clone the repository

$ git clone https://github.com/c2-server-hub/DiscordUtility
02

Install the single dependency

The only requirement is requests — no compiled extensions, no bloat.

$ pip install -r requirements.txt
03

Launch the tool

The CRT intro rolls first — any key skips it. Then the warning screen and a masked token prompt. After that, arrow keys drive everything.

$ python main.py
Your token is your account. Paste it nowhere except the tool's own masked prompt — anyone who holds it owns your account.

Read this before you run anything

DiscordUtility talks to Discord through private endpoints and a user authentication token. That is against Discord's Terms of Service, and Discord reserves the right to disable or permanently ban any account that does it. This project exists to study how Discord's API works — nothing more.

  • Self-bot automation breaks Discord's Terms of Service — it applies to every command here, even the harmless-looking ones.
  • Discord actively detects user-token traffic. Accounts get phone-locked, disabled, or permanently banned.
  • The authors take zero responsibility for your account. If you run this on a real account, the risk is entirely yours.

"If you only want to understand the API, read the source. Running a self-bot on an account you care about is never worth it."
